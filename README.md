# 역사의 전장

한국사 유닛을 영입하고 전장에 배치해 7개 시대의 전투를 돌파하는 브라우저 기반 PvE 자동 전투 프로토타입입니다.

- 53명의 유닛과 7개 챕터, 42개 라운드
- 6라운드마다 단독 거대 보스, 누적 3회 패배 시 종료
- 50개 증강, 국가와 역사적 역할 시너지, 종교 중첩 효과
- 브라우저에 현재 진행 상태 자동 저장

## 실행

`dist/` 폴더를 정적 웹 서버로 열면 됩니다. 별도의 빌드 단계나 서버 데이터베이스가 필요하지 않습니다.

## 현재 범위

게임은 실제 밸런스 검증 전의 프로토타입입니다. 일부 수치가 아직 미정이어서 시너지 단계와 스킬 세부 동작은 시험용으로 보완했습니다. 이동 경로·거리 판정 및 아이템 효과는 완성된 전투 시스템이 아닌 간략화된 형태입니다.
